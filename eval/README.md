# Набор для проверки

Фото лежат в `samples/` (не в git). Здесь — список и разметка: `samples.csv` (источник, лицензия, случай).

Apache-2.0 приложения не распространяется на фотографии. В CSV есть CC BY и CC BY-SA; запись в CSV не заменяет проверку страницы источника, автора и условий атрибуции. Фото, их обводки и наложения не входят в исходный релиз. Не публикуйте скачанные материалы или производные результаты без отдельной проверки прав.

Метрик-скрипта сейчас нет: `evaluate.py`/`consistency.py` меряли удалённый мм-путь. Приёмка обводки — наложение на фото в `out/` (см. «Сейчас» в `PLAN.md`); ошибка ладов считается в пикселях, не в мм.
