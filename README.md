# GuitarTrace

Фото гитары → линейная обводка (SVG / PNG): силуэт, гриф с ладами, колки и детали корпуса. Это не размерный чертёж: результат повторяет пропорции фото, а распознавание может требовать ручных правок. Работает на CPU, без интернета после установки зависимостей и моделей. При локальном запуске фото не отправляется во внешние сервисы.

Самостоятельное Python/FastAPI-приложение с браузерным редактором. Внешний сайт, аккаунт и платный API не нужны. Репозиторий: [Tw1nk1e/GuitarTrace](https://github.com/Tw1nk1e/GuitarTrace).

## Запуск

**Один раз:** установите [uv](https://docs.astral.sh/uv/getting-started/installation/). В PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Скачайте исходники репозитория с GitHub (ZIP) либо выполните:

```sh
git clone https://github.com/Tw1nk1e/GuitarTrace.git
cd GuitarTrace
```

Откройте терминал в папке с `pyproject.toml`. Python 3.12 при необходимости установит uv. Не копируйте чужую `.venv`.

**Установка и запуск из терминала (Windows / Linux):**

```sh
uv sync --frozen --python 3.12
uv run --frozen python scripts/fetch_models.py
uv run --frozen python -m gbcv.server --open
```

Откройте http://127.0.0.1:8000, если браузер не открылся сам. Команды выполняются из папки исходников; GPU и Node.js для работы приложения не нужны. Скачивание зависимостей и моделей требует интернета; модельные файлы проверяются по SHA-256. На macOS CPU-сборка PyTorch зависит от доступности колёс; проверяемые в CI платформы — Windows и Linux.

**В Windows можно также:** дважды щёлкнуть `Запуск.cmd` — он установит зависимости при запуске через uv и скачает отсутствующие модели.

- Первый запуск дольше: скачиваются модели (~380 МБ) и библиотеки (включая PyTorch, заметно больше самих моделей).
- Браузер откроется сам на http://127.0.0.1:8000 (если порт занят — на следующем, адрес будет в окне).
- Чтобы остановить сервис, закройте чёрное окно.

## Какое фото нужно

Лучше всего — **каталожное фото**: такое, как в интернет-магазине или на сайте производителя.

| Хорошо | Плохо |
|---|---|
| Гитара **целиком**, ничего не обрезано краем кадра | Обрезан корпус или голова |
| **Вид спереди**, камера смотрит прямо на деку | Снято сбоку или сильно под углом |
| **Прозрачный** (PNG/WebP) или **однотонный** фон | Пёстрый фон, другие гитары, стена с инструментами |
| Гитара одна, никто её не держит | Рука, ремень, стойка, кабель |
| Лады хорошо видны | Гриф в тени или засвечен |
| Чем крупнее, тем лучше: от ~2000 px по длинной стороне | Маленькая картинка-превью |

Форматы: JPEG, PNG, WebP, AVIF, до 25 МБ и 40 мегапикселей. Ориентация любая — гитара повернётся сама.

Стойка, блики и фон могут попасть в обводку. В редакторе можно удалить лишние объекты или стереть участки линий; автоматической очистки любого фото нет.

## Цикл работы

Интерфейс редактора — на английском.

1. **Откройте фото** — перетащите файл или нажмите кнопку **Open image**.
2. **Дождитесь обработки** — обычно 5–20 секунд, в зависимости от CPU и фото. По центру виден индикатор загрузки. Слева появится фото с обводкой, справа — векторный результат.
3. **Сверьте обводку с фото.** Колесо мыши — масштаб, `Space` + перетаскивание или средняя кнопка мыши — перемещение, **Fit** — показать целиком.
4. **Исправьте результат:**
   - **Select** — выбрать объект, переместить, повернуть или изменить размер; `Delete` — удалить.
   - **Auto select** — кликнуть по пропущенной детали на фото. SAM работает на CPU, разрешение запрашивается один раз на сеанс.
   - **Eraser** — стереть участок линии; **Bend** — поправить изгиб; **Nodes** — редактировать узлы открытых путей.
   - **Circle / Ring / Line / Rectangle** — добавить геометрию вручную.
   - `Ctrl+Z` — отменить правку, `Ctrl+Shift+Z` — повторить.
5. **Настройте вид** в **Document settings**: стиль линий **Bold / Thin / PNG**, видимость и прозрачность фото. Для выбранного объекта можно задать толщину линии.
6. **Сохраните результат:**
   - **SVG / PNG** — экспорт обводки без фото, выделения и элементов интерфейса. PNG — до 1500 px по длинной стороне, на белом фоне, в выбранном стиле линий.
   - **Save project** — файл `.gbcv.json` с геометрией и настройками, без исходного фото. **Open project** восстанавливает ручное редактирование без моделей; **Auto select** без исходного сеанса недоступен.
7. **Следующее фото** — перетащите новое; при несохранённых изменениях редактор запросит подтверждение.

Данные сеанса обработки хранятся в памяти сервиса. Редактор отправляет запрос закрытия при уходе со страницы; неактивные сеансы удаляются при следующем обращении к сервису после 30 минут. Если сеанс истёк — загрузите фото заново. Сервис рассчитан на локальный запуск, не на открытый многопользовательский хостинг.

## Если не получилось

| Сообщение | Что делать |
|---|---|
| `guitar not found` | Гитара не отделилась от фона — нужно фото на однотонном или прозрачном фоне |
| `frets not found` | Не видно ладов — нужно фото крупнее, вид спереди, гриф без тени |
| Деталь не выделилась | Покажите исходное фото, увеличьте его и кликните точнее инструментом **Auto select** |
| Обводка захватила лишнее | Выберите лишний объект и нажмите `Delete` либо сотрите участок инструментом **Eraser** |
| Сервис не стартует | Посмотрите текст ошибки в чёрном окне; проверьте, что установлен `uv` |

## Для разработчика

Python 3.12 через `uv` (системный `python` в Windows — заглушка Store, не использовать).

```sh
uv sync                                         # зависимости
uv run python scripts/fetch_models.py           # веса моделей → models/
uv run python -m gbcv.server --open             # веб-сервис
uv run python trace.py photo.webp              # обводка из терминала → out/<имя>/trace.svg, out/trace.html
uv run pytest                                   # тесты (модели не нужны)
uv build --out-dir out/release-check             # проверка сборки wheel и sdist
```

Node не требуется для работы сервиса. Для модульных тестов геометрии браузерного редактора нужен Node.js 22+: `node --test tests/editor_project.test.mjs tests/editor_erase.test.mjs tests/editor_bend.test.mjs tests/editor_nodes.test.mjs`. Браузерные проверки в `tests/*_browser.mjs` запускаются отдельно и могут требовать локальные материалы в `out/`.

Результат один — обводка: силуэт, накладка с ладами, колки и фурнитура. Размерный чертёж, JSON старой схемы и подгонка под модели удалены — см. `docs/decisions/0004-png-only.md`. Файл проекта `.gbcv.json` — отдельный формат редактора, не размерный чертёж.

### Использование из Python

Публичное название — GuitarTrace; имя пакета и внутренний модуль `gbcv`, расширение `.gbcv.json` и идентификатор формата проекта сохранены для совместимости. В окружении проекта можно вызвать тот же конвейер без веб-сервера:

```python
from gbcv.imageio import load_image
from gbcv.trace import trace, svg

rgba = load_image("photo.webp", mode="RGBA")
result = trace(rgba)
drawing = svg(result, style="png")  # SVG-строка с жирными линиями
```

Это пока внутренний API, не обещание стабильной библиотеки. Веса скачиваются отдельно через `scripts/fetch_models.py`; путь SAM пока привязан к расположению исходников. Веб-зависимости устанавливаются вместе с ядром. Параллельные вызовы с SAM требуют внешней сериализации: модель разделяет состояние изображения.

- Публикация исходников не означает готовность открыть сервис в интернет; аудит безопасности публичного сервера — отдельная задача.
- Приватность требует отдельной доработки перед внешним размещением: multipart-загрузки FastAPI могут попадать во временный файл, а очистка неактивных сеансов сейчас запускается по запросам, не фоновым таймером. Строгая гарантия «оригинал только в RAM и не дольше обработки» пока не обеспечена.

- Устройство и правила проекта — [`AGENTS.md`](AGENTS.md), этапы — [`PLAN.md`](PLAN.md), историческое ТЗ — [`docs/brief.md`](docs/brief.md), решения — [`docs/decisions/`](docs/decisions/).
- Модели: BiRefNet — отделение гитары от фона, SAM 2.1 — детали. Источники весов и отдельные лицензионные условия — в уведомлениях. Вычисления на CPU.
- Настройки через переменные окружения: `GBCV_HOST`, `GBCV_PORT`, `GBCV_MAX_FILE_MB`, `GBCV_MAX_MEGAPIXELS` (пример — `.env.example`). Файл `.env` автоматически не читается: переменные нужно передать процессу через оболочку или настройки запуска.
