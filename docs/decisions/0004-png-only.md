# 0004. Только обводка: PNG вместо JSON и миллиметров

Дата: 2026-11-09. Статус: принято (решение человека).

## Что решено

- Результат — обводка: силуэт, накладка с ладами, колки и фурнитура. Внутри сервиса SVG; самостоятельный редактор экспортирует SVG и PNG.
- Абсолютных миллиметров нет: рисунок повторяет пропорции фото. Размерные линии, вид сбоку и сечения не делаем.
- Подгонка под модели (шаблоны семейств, типовые раскладки деталей, модельные правила) не используется.
- JSON как внешний контракт размерного чертежа отменён. Файл проекта редактора `.gbcv.json` — отдельный формат, не такой контракт.

## Что удалено

`run.py`, `pipeline.py`, `templates.py`, `parts.py`, `schema.py`, `render.py`, `debug.py`, `templates/`, `schema/`,
`renderer/`, `scripts/build_templates.py`, `eval/evaluate.py`, `eval/consistency.py`, `eval/references.csv`.
`_orient_and_split`, `_remove_thin_bits` и `FOCAL` перенесены из `pipeline.py` в `orient.py`.

## Следствия

- Лады перестают быть линейкой для мм: нужны только найденные линии, без мензуры, номера лада и модели наклона
  камеры. Веерные лады — не особый случай, а просто наклонные отрезки.
- «мм» в коде становятся условными единицами (номинальный масштаб от длины силуэта) для толщин линий и порогов
  сглаживания/SAM; в результат они не выходят.
- Это решение само по себе не меняет лицензии и приватность; актуальные ограничения — в `README.md`, `docs/licensing.md` и `THIRD_PARTY_NOTICES.md`.
