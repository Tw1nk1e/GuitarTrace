# 0001. Исторический JavaScript-генератор (отменено)

Дата исходного решения: 2026-10-28. Заменено решением 0004 от 2026-11-09.

Ранее SVG строился отдельным параметрическим JS-генератором из JSON. Генератор и его Node CLI удалены. Самостоятельное приложение строит SVG в Python; браузерный JavaScript отвечает за ручное редактирование. Node нужен только для отдельных тестов, внешняя интеграция не требуется.

Неиспользуемый исторический образец исключён из текущего дерева при подготовке публичного релиза. Его происхождение и возможная связь с оставшимися фрагментами описаны в `../licensing.md`; исключение образца не является подтверждением прав на производный код.
