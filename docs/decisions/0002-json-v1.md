# 0002. Формат результата JSON v1

Дата: 2026-10-28. Статус: принято (одобрено человеком 2026-10-28). Заменено 0004 (2026-11-09).

Источник правды — `src/gbcv/schema.py`; JSON Schema для других языков — `schema/blueprint.v1.schema.json` (генерируется).

## Координаты
- Миллиметры. X вдоль гитары: X = 0 — торец корпуса, голова справа. Y поперёк: Y = 0 — центр струн, Y < 0 — басовая сторона.
- Порожек — `neck.nut_x`. Подставка (линия сёдел) — `nut_x - scale_length`. Лад n — `bridge_x + scale_length / 2^(n/12)`.

## Отличия от черновика в брифе
1. **`neck.nut_x`** — добавлено. Без него лады не привязаны к корпусу.
2. **`corners`** у контуров — индексы точек, где кривая ломается (ухо головы, острый рог). Без них Catmull-Rom скругляет всё. Точки остаются простыми парами `[x, y]`.
3. **Порядок точек** корпуса и головы: открытый путь от басовой стороны (Y < 0) к дисканту (Y > 0). Корпус — от выхода грифа вокруг торца обратно к грифу; голова — от порожка вокруг вершины обратно к порожку. Разрыв закрывает гриф / линия порожка.
4. **`head.points`** — всегда полный контур, даже при `symmetric: true` (флаг — подсказка, потребителю не нужно отражать).
5. **`pickguard`** — необязательный контур накладки (этап 5).
6. **`parts[].type`** — закрытый список (см. `PartType`), расширяется в v1 без смены версии; неизвестный тип генератор пропускает.

## Предупреждения
Строки `snake_case`. Известные: `stub_pipeline`, `perspective_high`, `frets_not_found`, `cropped`, `occluded`, `low_contrast_edge`. Список расширяется без смены версии.

## Версия
`version: 1`. Ломающие изменения → `version: 2` и миграция у потребителя.
